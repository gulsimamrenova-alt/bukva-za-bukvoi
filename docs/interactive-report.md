# Отчёт по интерактивным элементам — 22 октября 2026

## Реализовано
- Плавающая кнопка «Наверх» появляется после 550 px прокрутки, плавно возвращает к началу и переводит фокус на заголовок. На узком экране скрыта, пока фокус находится в форме.
- Демонстрационная форма: имя, email, сообщение. Проверка обязательных полей, email и пустого текста из пробелов. Анимация галочки и сообщения об успехе; повторная демонстрация с очисткой полей. Никакой отправки или постоянного хранения.
- Числа 3/4/1 — реальные параметры макета, а не статистика учеников. Запускаются при появлении и не перезапускаются при повторном скролле.
- Трёхполосная гамбургер-иконка превращается в крестик; меню закрывается при выборе секции, Escape, клике снаружи и переходе на широкий экран. Фокус поддерживается.
- Основной и скачиваемый index.html автономны: встроены CSS, JavaScript, SVG и три шрифта вместе с лицензиями. Внешние библиотеки и сервер не нужны для демонстрации.

## Проверки
Среда: автоматизированный Chromium/Playwright, эмуляция мобильного браузера. Физические iPhone/Android и встроенные браузеры всех мессенджеров не проверялись.

Проверенные размеры: 320×568, 360×800, 390×844, 430×932, 768×1024, 844×390, 1440×1000. Горизонтальной прокрутки нет. Исправлен выход фоновой фигуры в альбомном формате.

PASS: показ/скрытие и действие кнопки Наверх; меню и клавиатурный фокус; запуск и финальные значения счётчиков; запрет некорректного email и пустого сообщения; анимация успеха; повтор формы; отсутствие POST/fetch/XHR и записей в localStorage/sessionStorage; режим уменьшенного движения; без JavaScript видимы содержание и статичные числа, отправка заблокирована; автономный HTML работает в изолированном офлайн-документе браузера без внешних запросов; кнопка скачивания выдаёт index.html с точным содержимым готового файла.

Отдельная проверка файлового протокола file:// в этой среде недоступна из-за политики браузера. Автономность проверена в изолированном документе без сети. Эмуляция Chromium не заменяет проверку на физическом Safari.

## Ограничения мессенджеров
HTML-файл не может принудительно разрешить запуск JavaScript или открытие вложения, если это запрещает мессенджер/просмотрщик. Для просмотра достаточно общей HTTPS-ссылки; скачанный файл при необходимости открывается через «Открыть в браузере». Если мессенджер показывает исходный код или не запускает вложение, следует воспользоваться ссылкой или открыть скачанный HTML в обычном браузере.

## Поддержка
Редактируемые исходники: src/index.html, src/style.css, src/app.js. Сборка: python3 scripts/build-standalone.py. Результат: dist/index.html и идентичный dist/download/index.html. Без дополнительных зависимостей сборки. Изменения курса остаются демонстрационными; реального приёма сообщений нет.
