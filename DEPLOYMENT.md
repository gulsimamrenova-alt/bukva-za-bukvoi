## Что подготовлено

Статический демонстрационный лендинг курса почерка для детей 7–10 лет. Сохранены дизайн, анимации, мобильное меню, кнопка «Наверх», счётчики и форма с визуальным подтверждением. Форма не отправляет сообщения. Пароли, ключи API и переменные окружения для этой версии не нужны.

## Подключение репозитория в Vercel

1. В существующем проекте Vercel `bukva-za-bukvoi` проверьте Settings → Git: репозиторий должен быть `gulsimamrenova-alt/bukva-za-bukvoi`. Не создавайте второй проект без необходимости. При первом импорте выбирайте этот же репозиторий.
2. Production Branch: `main`. Root Directory: корень репозитория (`.`).
3. Framework Preset: Other. Node.js: 24.x.
4. Команды и каталог результата заданы в `vercel.json`: установка `npm ci --ignore-scripts --no-audit --no-fund`, сборка `npm run build`, Output Directory `public`.
5. Environment Variables для демонстрационной версии не нужны. Нажимать Deploy или отправлять изменения в main только после проверки и подтверждения владельцем.

Сведения об имени проекта и адресе Vercel предоставлены владельцем. Git remote проверен отдельно; настройки Git Integration внутри аккаунта Vercel через это действие не изменялись.

## Локальная проверка

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run check
```

Откройте `public/index.html` в обычном браузере либо отдайте каталог `public` любым статическим HTTP-сервером. Автономный файл для передачи: `public/download/index.html`. На Vercel для него настроен заголовок скачивания с именем `index.html`.

Редактируемые файлы: `src/index.html`, `src/style.css`, `src/app.js`. Шрифты и их лицензии — в `assets/`. Node-скрипт сборки встраивает стили, скрипты, шрифты, favicon и лицензии в единый HTML. Результат создаётся в `public/` и не хранится в Git: Vercel воспроизводит его при сборке. Python и npm-зависимости не требуются.

Рабочее название курса и материалы остаются демонстрационными; город, расписание, цена и данные преподавателя заполняются позже. `noindex` сохранён для черновой версии. Перед реальным запуском необходимо утвердить содержание и отдельно подключить обработку обращений, если она понадобится.
